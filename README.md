# NalApps Child Theme

A tiny, settings-free WordPress plugin that creates and activates a child theme for the currently active parent theme.

## Features

- One-click child theme creation
- Automatic activation
- Copies the parent theme screenshot when available
- Avoids duplicate child stylesheet loading
- No settings
- No ads
- No tracking
- No external API calls

## Usage

1. Install and activate the plugin.
2. Open **Appearance → Create Child Theme**.
3. Click **Create and Activate Child Theme**.

## Requirements

- WordPress 6.2 or later
- PHP 7.4 or later
